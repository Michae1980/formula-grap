# Formula Graph（公式知识图谱）

将数学及跨学科公式之间的推导、特例、等价与引用关系构建为结构化有向属性图，支持按学科/学段/专题筛选直接关联公式，并在任意两个关联公式之间切换 **L1 摘要 / L2 标准 / L3 详细** 三级推导过程。

## 项目定位

- **首期 MVP 范围**：中国初中、高中核心数学公式（目标 200–300 个），当前已完成高中三角函数与解三角形 25 公式种子库。
- **长期扩展方向**：预留量纲、国际单位制（SI）单位与跨学科应用级依赖字段，后续平滑扩展至微积分、线性代数、物理学与化学。

## 快速体验原型

直接用现代浏览器打开 `prototype/index.html` 即可离线运行（联网时自动启用 KaTeX 渲染出版级数学公式），支持：

1. 点击任意公式卡片高亮前置依赖、直接衍生与双向等价节点，或开启「仅看直接关联」聚焦局部子图。
2. 按学段、专题或关键词搜索过滤公式。
3. 点击连线标签或详情面板按钮，在 L1 摘要、L2 标准与 L3 详细（含易错提醒）三档推导视图间切换。
4. 使用顶部路径检索器计算任意两个公式之间的最短推导链。
