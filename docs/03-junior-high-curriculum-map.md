# 初中学科公式图谱规划（数学 + 科学）

> 更新日期：2026-11-23  
> 适用范围：中国义务教育阶段（7–9 年级）数学与科学（物理、化学定量部分）

## 1. 为什么先聚焦初中（数学 + 科学）

1. **总量可控、闭环更快**：初中数学核心公式约 85–100 个，初中科学（物理 + 化学）定量公式约 55–70 个，合计 **140–170 个公式**即可形成高密度、无断点的跨学科知识图谱。
2. **天然具备跨学科桥梁**：初中物理大量核心定律直接建立在初中数学的比例函数、一次函数、相似三角形与一元二次方程之上，能第一时间验证本项目的量纲体系（`quantity_kind` / `dimension` / `si_unit`）与跨学科筛选能力。
3. **教学价值清晰**：初中阶段的推导链条短而完整（如完全平方公式 → 配方法 → 求根公式 → 韦达定理；欧姆定律 + 电功率 → 焦耳定律），非常适合展示 L1 / L2 / L3 三级详略切换。

## 3. 重点跨学科桥梁（数学 ↔ 科学）

- **正比例/反比例函数 ↔ 物理定义式**：$v=s/t$、$\rho=m/V$、$I=U/R$ 中的控制变量关系与图像斜率/面积意义（`dependency_site: "application_level"`）。
- **完全平方与二次函数最值 ↔ 电功率极值**：串联滑动变阻器电功率 $P = I^2 R$ 的最大值推导。
- **勾股定理与相似三角形 ↔ 光学与力学**：小孔成像比例、杠杆力臂几何计算、斜面机械效率。
- **一元一次/分式方程 ↔ 化学溶液配制**：稀释与浓缩过程中的溶质质量守恒方程。

## 4. 首批初中种子子图切入顺序

建议按以下三批推进，每批 15–20 个公式，边录入边在原型中验收：

1. **Batch 1（跨学科验证子图 · 约 18 个公式）**：初中电学核心链（串并联 + 欧姆定律 + 电功 + 电功率 + 焦耳定律）+ 数学正/反比例函数桥梁节点，一次性验证数学与物理跨学科筛选及量纲表渲染。
2. **Batch 2（初中代数主链 · 约 20 个公式）**：乘法公式 → 因式分解 → 配方法 → 一元二次方程求根公式 → 韦达定理 → 二次函数图像与最值。
3. **Batch 3（初中力学与化学定量 · 约 25 个公式）**：密度 → 重力 → 压强 → 液体压强 → 浮力 → 功与机械效率，以及溶液质量分数与溶解度换算。
