# 项目计划与架构设计（Formula Graph）

> 创建日期：2026-11-23  
> 当前状态：已调整重心，优先推进中国初中学科（数学 + 科学/物理与化学）

## 1. 核心目标

构建一套「有向属性图数据层 + Web 优先交互前端」的公式知识图谱系统：

1. 选中任意公式后，按学科、学段或专题筛选并展示直接关联公式（前置依赖、直接衍生、等价变形与跨学科引用）。
2. 在关联公式之间提供 **L1 摘要 / L2 标准 / L3 详细** 三级详略推导视图，支持步骤内引用公式跳转。
3. 首期聚焦**中国初中数学与初中科学（物理、化学定量部分）**，合计约 140–170 个核心公式，第一时间验证跨学科量纲建模与推导联动；后续再向高中及大学学科扩展。

## 2. 核心数据模型与扩展架构

采用属性图模型，将“公式实体”“推导关系”与“多维分类”彻底解耦（详见 `schema/formula-graph.v1.schema.json`）：

- **公式节点（`formulas[]`）**：包含唯一命名空间 ID（`<discipline>.<subdomain>.<slug>`）、规范名称、别名、LaTeX 表达式、成立条件、核验状态，以及借鉴 MathModDB 设计的变量表（符号、数学类型、定义域、`quantity_kind`、`dimension`、`si_unit`）。
- **推导关系（`derivations[]`）**：原生支持 1 对 1 与多对一前提依赖（`from_formula_ids[]`），记录关系类型（`derives_to` / `special_case_of` / `generalizes` / `equivalent_to` / `simplifies` / `applies_in`）、借鉴 Lean Atlas 的依赖层级（`definition_level` / `proof_level` / `application_level`）、原子推理规则标签，以及 L1/L2/L3 三档推导内容。
- **正交多维标签树（`taxonomy`）**：将 `disciplines`、`education_stages` 与 `topics` 设为正交数组，允许同一公式归属多个领域与学段。

## 3. 初高中数学 MVP 范围与录入策略

参考中国义务教育与普通高中数学课程标准主线，初高中核心公式分为六个模块：

1. 数与代数
2. 方程与不等式
3. 函数与导数初步
4. 平面与立体几何
5. 三角函数与解三角形（**已完成 25 公式种子库**，见 `data/cn-senior-high/trig-seed-25.json`）
6. 解析几何与概率统计

源数据采用 JSON + Git 版本管理，遵循「大语言模型辅助起草 + 人工数学严谨性核验 + 自动化脚本校验」流程。

## 4. 推荐技术栈

| 层级 | 推荐方案 | 选型依据 | 后续扩展路径 |
| :--- | :--- | :--- | :--- |
| 前端框架 | React + TypeScript（Next.js 或 Vite） | 强类型约束适配复杂公式图谱 Schema | 静态导出或封装为桌面端/移动端应用 |
| 公式渲染 | KaTeX | 渲染速度快、图谱内无闪烁 | 接入物理/化学方程式时按需启用 mhchem |
| 图谱可视化 | React Flow + Dagre / Cytoscape.js | 支持自定义公式卡片、分层布局与子图裁剪 | 超千级节点切换 WebGL 引擎（如 Sigma.js） |
| 数据与图计算 | 静态 JSON + Graphology | MVP 阶段零后端运维成本，内置最短路径算法 | 规模扩大后平滑迁移至 Neo4j 或 PostgreSQL |

## 6. 主要风险与前置对策

- **多对一推导建模**：已通过 `from_formula_ids[]` 数组与独立推导对象在 Phase 0 彻底解决。
- **符号与教材口径差异**：通过 `aliases[]`、规范变量说明与来源标注统一口径。
- **图谱视觉过载**：采用分层泳道排布 + 默认高亮选中公式 1 跳邻域 + 「仅看直接关联」聚焦模式控制同屏信息密度。
